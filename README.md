# Weather App

Real-time weather application with city search, favorites list, and 5-day forecast.

**Weather-App:** [https://weather-app-v2-sable.vercel.app](https://weather-app-v2-sable.vercel.app)

## Features
- Search cities and view current weather
- Add/remove cities to favorites list
- Display temperature, humidity, wind speed, pressure
- 5-day weather forecast
- Fully responsive design
- Built with React, Tailwind CSS, OpenWeatherMap API

## Tech Stack
- React
- Tailwind CSS
- JavaScript (ES6+)
- HTML5
- CSS3
- OpenWeatherMap API
